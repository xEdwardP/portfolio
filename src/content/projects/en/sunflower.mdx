A desktop point of sale and inventory system for small and medium businesses. It is the only
desktop project in this portfolio, and it is here precisely for that reason: WinForms imposes
different constraints than the web and forces different decisions.

The architecture is **three layers with a strictly unidirectional dependency flow**:
`Presentation` → `Services` → `Repository` → SQL Server. The presentation layer **never**
talks to the database; it consumes service interfaces, which in turn delegate to repository
interfaces.

That matters more in WinForms than on the web, because the form is traditionally where
everything piles up. Here dependency injection comes from the **.NET Generic Host**, so forms
receive their services through the constructor instead of instantiating them, and data access
uses ADO.NET against stored procedures.

It covers the full cycle: catalogs, stock control, sales with automatic invoicing, sales
history, profitability reports, user administration with role-based menus, and a business
profile with a cloud-hosted logo.
