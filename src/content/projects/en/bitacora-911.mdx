## The problem

Tracking institutional activities requires consistent records, a searchable history and
access to information according to each user's responsibilities.

Bitácora 911 brings this work together in an internal web application, currently **in
production and in use within the institution**.

## The solution

The application lets users record activities, consult their history and add clarification
notes. Dashboards and modules display the information each user is authorized to access,
with access checks also enforced on the server.

Reports can be exported in spreadsheet and document formats. Large selections are processed
in the background to keep the interface available while reports are generated.

## Implementation

The project uses Laravel, PHP and MySQL, with Livewire, Blade, Alpine.js and Tailwind CSS
for the interface. It includes user and permission management, auditing and automated
functional and interaction tests.

## Outcome

An institutional tool in production that brings recording, lookup and reporting into one
environment. The source code and application access are private.
