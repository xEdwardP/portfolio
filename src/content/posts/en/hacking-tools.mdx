## 🔄 0. System maintenance

```bash
# Keep Kali up to date — run regularly, especially before a long CTF session
sudo apt update && sudo apt upgrade -y
```

⭐ **Recommended to add:**

```bash
# Periodic cleanup of orphan packages/cache, keeps the VM from filling up with junk
sudo apt autoremove -y && sudo apt autoclean
```

## 📚 1. Wordlists and dictionaries

| Tool            | Install                     | Use                                                                                                                                         |
| --------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **SecLists** ✅ | `sudo apt install seclists` | The most complete collection of wordlists (directories, subdomains, passwords, fuzzing payloads, etc.). Installs to `/usr/share/seclists/`. |

⭐ **Recommended to add:**

| Tool                     | Install                                           | Why                                                                                                                                                                          |
| ------------------------ | ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **CeWL**                 | `sudo apt install cewl`                           | Generates custom wordlists from a website’s text content — very useful when the target has passwords/users based on its own content (employee names, internal jargon, etc.). |
| **crunch**               | `sudo apt install crunch`                         | Generates tailored wordlists with specific patterns (length, charset, known prefixes/suffixes) when `rockyou.txt` is not enough.                                             |
| **rockyou.txt** (verify) | `sudo gunzip /usr/share/wordlists/rockyou.txt.gz` | Comes preinstalled compressed in Kali; confirm you have it decompressed, since it is used constantly.                                                                        |

## 🎯 5. Active Directory / Windows exploitation

| Tool            | Install                                                                                                         | Use                                                                                                                                                                   |
| --------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Impacket** ✅ | `git clone https://github.com/fortra/impacket.git` (current official repo, after the migration from SecureAuth) | Python script suite for Windows/AD protocols (SMB, Kerberos, WMI, DCOM). Includes `secretsdump.py`, `psexec.py`, `GetUserSPNs.py`, `smbclient.py`, among many others. |

⭐ **Recommended to add (for more Active Directory machines):**

| Tool                        | Install                                                         | Why                                                                                                                                                          |
| --------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **BloodHound + SharpHound** | `sudo apt install bloodhound`                                   | Maps privilege relationships in Active Directory and visualises attack paths (user → group → object → Domain Admin). The de-facto standard in AD pentesting. |
| **CrackMapExec / NetExec**  | `pipx install netexec` (CME is deprecated in favour of NetExec) | A “Swiss army knife” to validate credentials and run commands against Windows/AD networks at scale (SMB, WinRM, MSSQL, LDAP).                                |
| **Evil-WinRM**              | `gem install evil-winrm`                                        | Interactive shell over WinRM for Windows machines — the SSH equivalent for Windows Remote Management, widely used once you have valid credentials.           |
| **Responder**               | `sudo apt install responder`                                    | Captures NTLM hashes on local networks by exploiting LLMNR/NBT-NS poisoning — a classic in internal network assessments.                                     |
| **kerbrute**                | `go install github.com/ropnop/kerbrute@latest`                  | User enumeration and password brute force against Kerberos, much quieter than other methods.                                                                 |

## 📦 6. Manually downloaded tools (post-exploitation / Windows)

| Tool                                           | Source                                                                    | Use                                                                                                                            |
| ---------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **nc64.exe** ✅                                | [int0x33/nc.exe](https://github.com/int0x33/nc.exe)                       | Netcat compiled for Windows — essential for reverse/bind shells on compromised Windows machines, since it is not preinstalled. |
| **winPEASx64.exe** ✅                          | [PEASS-ng releases](https://github.com/carlospolop/PEASS-ng/releases)     | Automatic enumeration script for Windows privilege-escalation vectors (the `linpeas.sh` equivalent).                           |
| **“TheGoodHacker” / hackerpwm environment** ✅ | [thegoodhackertv/hackerpwm](https://github.com/thegoodhackertv/hackerpwm) | A personal working environment/template for pentesting.                                                                        |

⭐ **Recommended to add to this same portable-tools folder:**

| Tool                                   | Source                                                                                                                                      | Why                                                                                                                                                                                                                                                                   |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **linpeas.sh**                         | [PEASS-ng releases](https://github.com/carlospolop/PEASS-ng/releases)                                                                       | The Linux equivalent of winPEAS — already mentioned in the cheat sheet, but confirm you have the latest version downloaded locally (useful to serve via `python3 -m http.server` when the victim machine has no internet access).                                     |
| **LinEnum.sh**                         | [rebootuser/LinEnum](https://github.com/rebootuser/LinEnum)                                                                                 | A lighter/faster alternative to linpeas when you only need a basic check.                                                                                                                                                                                             |
| **pspy64**                             | [DominicBreuker/pspy](https://github.com/DominicBreuker/pspy)                                                                               | Monitors processes on Linux **without root privileges**, ideal for detecting cronjobs/scripts running as root in real time (the same vulnerability pattern seen in Archangel, Easy Peasy and Fowsniff CTF, but automated instead of reading `/etc/crontab` manually). |
| **mimikatz**                           | [gentilkiwi/mimikatz](https://github.com/gentilkiwi/mimikatz)                                                                               | Extracts credentials from memory on Windows (NTLM hashes, Kerberos tickets, plaintext passwords from LSASS) — a Windows post-exploitation standard.                                                                                                                   |
| **PowerUp.ps1** / **PrivescCheck.ps1** | [PowerShellMafia/PowerSploit](https://github.com/PowerShellMafia/PowerSploit) / [itm4n/PrivescCheck](https://github.com/itm4n/PrivescCheck) | winPEAS equivalents for Windows privilege-escalation enumeration via PowerShell.                                                                                                                                                                                      |
| **Chisel**                             | [jpillora/chisel releases](https://github.com/jpillora/chisel/releases)                                                                     | A _pivoting_/TCP-over-HTTP tunnelling tool — widely used to forward internal ports (as done manually with `ssh -L` in VulnNet: Internal) when SSH is not available as a tunnel vector.                                                                                |
| **ligolo-ng**                          | [nicocha30/ligolo-ng](https://github.com/nicocha30/ligolo-ng)                                                                               | A modern alternative to Chisel for pivoting, with a virtual network interface — increasingly popular on HTB/THM for multi-hop internal networks.                                                                                                                      |

| Tool              | Install                              | Use                                                                                                                        |
| ----------------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| **OpenJDK 11** ✅ | `sudo apt install openjdk-11-jdk -y` | A Java requirement for tools like Maven, BloodHound (old), Burp Suite, or Java exploits.                                   |

| Tool            | Install                           | Why                                                                                                                                                                                                                                |
| --------------- | --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| **Go (golang)** | `sudo apt install golang-go`      | Many modern recon tools (`ffuf`, `subfinder`, `kerbrute`, `naabu`, `httpx`) are written in Go and installed via `go install`; having it ready avoids friction when trying new community tools.                                     |
| **.NET SDK**    | `sudo apt install dotnet-sdk-8.0` | Needed to compile/run some offensive C# tools aimed at Windows/AD (e.g. Rubeus, SharpHound in its .NET variant).                                                                                                                   |

## 📝 Final notes

- Run `sudo apt update && sudo apt upgrade -y` regularly (ideally before each CTF session), and complement it with `sudo apt autoremove -y` now and then.
- For tools installed via `pip3 --break-system-packages`, consider gradually migrating to `pipx` to avoid breaking the system Python as you accumulate more third-party scripts.
- Keep a central folder (e.g. `~/tools/`) for all manually downloaded binaries (winPEAS, linpeas, nc64.exe, mimikatz, chisel, etc.), and serve them with `python3 -m http.server` when needed inside a compromised machine — so you do not depend on each machine having internet access.
- `searchsploit -u` and `sudo msfdb init` / updating Metasploit are worth doing periodically, since both exploit databases update constantly.
