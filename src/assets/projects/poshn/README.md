# Imágenes de PosHn

Agrega capturas como `01.png`, `02.png` y `03.png` en esta carpeta.
Formatos admitidos: PNG, JPG, JPEG, WebP y AVIF, con extensiones en minúsculas.

La primera imagen en orden alfabético será la portada y todas aparecerán automáticamente
en la galería en español e inglés. Mientras no haya imágenes, la galería permanece oculta.

Usa datos de demostración y evita mostrar credenciales o información privada.

Agrega las descripciones en español e inglés en `src/data/project-screenshots.ts`,
dentro de `poshn`, usando el nombre exacto de cada archivo.
