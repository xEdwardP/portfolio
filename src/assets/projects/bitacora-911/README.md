# Imágenes de Bitácora 911

Agrega aquí las capturas públicas del proyecto con nombres como `01.png`, `02.png` y
`03.png`. Se admiten PNG, JPG, JPEG, WebP y AVIF, con extensiones en minúsculas.

La primera imagen en orden alfabético se usa como portada. Todas aparecen automáticamente
en la galería de las versiones en español e inglés, sin cambios de código.

Usa capturas con datos ficticios y sin información confidencial ni identificadores internos.
Mientras no haya imágenes, la galería permanece oculta.

Para describir una captura a lectores de pantalla, agrega su nombre de archivo y sus
textos en español e inglés en `src/data/project-screenshots.ts`, dentro de `bitacora-911`.
